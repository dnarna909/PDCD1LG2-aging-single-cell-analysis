scRNA-seq analysis

The dataset analyzed in the current workflow was the Healthy pediatric and adult human liver tissue dataset55.The single-cell RNA-sequencing dataset in .h5ad format was obtained from publicly available CELLxGENE resources (https://cellxgene.cziscience.com/collections/ff69f0ee-fef6-4895-9f48-6c64a68c8289?). The analysis workflow was designed to evaluate the cellular source of PD-L2 (PDCD1LG2: ENSG00000197646) in vivo. Data were imported into R as Seurat objects using the anndataR and Seurat packages. Cell metadata were extracted from the Seurat object and merged with gene expression values using cell barcodes. Cell type annotations were obtained from the cell_type metadata field. To reduce potential confounding from cell types identified in fewer than 6 donor datasets and cell types lacking nuclei, erythrocytes, platelets, neutrophils, and conventional dendritic, cycling plasma, and cycling myeloid cells were excluded prior to analysis. Dimensionality reduction plots were generated using the available UMAP embedding to inspect cell type distributions after filtering. Genes not detected in the expression matrix were excluded from the corresponding analysis. Cell-level expression data were merged with donor and sample metadata. All analyses were performed in R using the Seurat, anndataR, dplyr, tidyr, stringr, broom, ggplot2, ggpubr, scales, and fs packages.
